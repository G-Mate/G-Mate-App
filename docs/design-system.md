# 디자인 시스템

temi 머리 태블릿(가로 10인치대)을 허리 높이에서 서서 보고 누르는 키오스크 화면 기준입니다.
방향은 **절제된 모던**입니다. 화면의 큰 면은 학교 로고에서 가져온 남색 하나, 강조는 파랑 하나만 씁니다. 회색 바탕 위에 흰 카드를 그림자 없이 1px 선(`outlineVariant`)으로만 나눠 올리고, 그라데이션·빛 번짐·색 그림자·아이콘 배지 같은 장식은 쓰지 않습니다. 남색 패널도 단색이고, 장식은 패널 오른쪽 위의 가는 선 평면도(교실 칸과 목적지까지의 점선 경로) 하나뿐입니다. 아이콘은 직접 그린 `GmIcon`(둥근 선 + 옅은 면의 두 톤)을 씁니다. 디자인 포인트는 장식이 아니라 남색 패널과 흰 영역의 화면 분할, 큰 제목과 작은 설명의 크기 대비로 만듭니다.
글꼴은 Pretendard(SIL OFL 1.1, `assets/fonts/pretendard/`)를 앱에 넣어 씁니다. 색을 조정할 때는 `app_colors.dart`만 바꾸면 됩니다.

## 쓰는 법

```dart
import 'package:g_mate/core/design_system.dart';
```

- 테마는 `AppTheme.light()`로 `lib/app/app.dart`에서 이미 적용되어 있습니다.
- 색은 `context.colors`(Material `ColorScheme`)와 `context.appColors`(성공·주의·위험 같은 의미 색)로 꺼냅니다. 화면에서 `Color(0x...)`를 직접 쓰지 않습니다.
- 글자는 `context.textStyles.titleLarge`처럼 테마 스타일을 씁니다. `fontSize`를 직접 쓰지 않습니다.
- 간격·크기는 `AppSpacing`, `AppRadius`, `AppSize` 상수를 씁니다.
- 앱을 띄운 뒤 `/design-gallery` 경로로 가면 토큰과 공통 위젯을 한 화면에서 볼 수 있습니다.

## 키오스크 기준

- 방문객 화면의 누르는 요소는 최소 64dp, 주 버튼은 72dp입니다. 48dp(`GmButtonSize.small`)는 관리 모드에서만 씁니다.
- 관리 모드 화면은 가까이서 조작하므로 `GmDenseTheme`(`AppTheme.dense`)으로 감싸 글자·입력 칸·칩을 한 단계(0.8배) 줄입니다.
- 본문은 22sp 이상입니다. 60cm~1m 떨어져서 읽을 수 있는 크기입니다.
- 화면 좌우 여백은 48dp입니다 (`GmScaffold`가 넣어 줍니다).
- 글꼴은 Pretendard 5가지 굵기(400~800)를 씁니다. 큰 글자일수록 자간을 크기의 -2~-3%로 좁힙니다.
- v1은 라이트 테마만 둡니다.

## 공통 위젯

| 위젯 | 용도 |
| --- | --- |
| `GmScaffold` | 화면 틀. 뒤로 가기·작은 머리말·제목·오른쪽 동작, 여백 잡힌 본문, 하단 고정 버튼 줄 |
| `GmButton` | 버튼. `primary`/`secondary`/`outline`/`danger`, 크기 `large`/`medium`/`small`, 아이콘, `loading` |
| `GmMenuTile` | 홈 화면의 큰 메뉴 카드. 왼쪽 위 선 아이콘, 오른쪽 위 번호(`index`) 또는 짧은 글자(`badge`), 아래 큰 제목·작은 설명·화살표. `emphasized`면 파랑 단색 면(주 메뉴 하나에만) |
| `GmHeroPanel` | 화면 한쪽을 채우는 남색 단색 패널. 머리말·큰 제목·부제·하단 위젯, 오른쪽 위 가는 선 평면도(`showFloorPlan`, 이동 중 화면은 끔). 맨 위에는 `GmHeroBackButton`을 둘 수 있음 |
| `GmIcon` | 직접 그린 아이콘 `GmIcons`(길 찾기, 투어, 과학실, 컴퓨터실, 교무실, 행정실, 도서관, 강당, 교실, 장소, 화살표). 24 격자, 둥근 선 + 옅은 면 |
| `GmSplitLayout` | 왼쪽 남색 패널 + 오른쪽 본문 화면 틀 (홈, 장소 확인, 도착, PIN) |
| `GmPlaceCard` | 장소 카드: 사진이 있으면 사진 + 이름 + 층·분류, 없으면 왼쪽 위 선 아이콘과 아래 이름·층·분류·화살표만 둔 글자 중심 카드 |
| `GmCard` | 흰 카드. 누를 수 있고 `selected` 표시 지원 (장소 카드 등) |
| `GmChoiceChip` | 카테고리 필터 |
| `GmStatusBanner` | 로봇 상태·안내 메시지 띠. `info`/`success`/`warning`/`danger` |
| `GmStatusIndicator` | 점 + 짧은 글자로 된 작은 상태 표시 (남색 패널 위에서도 사용) |
| `GmEmptyState` | 목록이 비었을 때 가운데 안내 |

새 공통 위젯은 `lib/core/widgets/`에 `gm_` 접두사로 만들고 `lib/core/design_system.dart`에서 export 합니다.
기능 하나에서만 쓰는 위젯은 그 기능의 `presentation/widgets/`에 둡니다.

## 화면

시안은 실제 기능 화면으로 옮겼습니다(시안 코드는 지움). 경로는 `lib/app/routes.dart`에 있고, 화면 정의는 Notion 기능 > 화면 정의에 있습니다.

| 화면 | 구성 |
| --- | --- |
| 홈 (`/`) | 왼쪽 남색 패널(인사말, 로봇 상태), 오른쪽 메뉴 카드 [길 찾기](파랑 주 메뉴) [학교 투어](준비 중). 남색 패널을 3초 누르고 있으면 관리 모드 PIN |
| 장소 선택 (`/places`) | 머리말 + 제목, 오른쪽 위 검색창, 분류 칩, 장소 카드 3열 |
| 장소 확인 (`/places/:key`) | 왼쪽 남색 패널(층·분류, 장소 이름), 오른쪽 소개 카드(장소 아이콘, 아래쪽 설명. 사진이 생기면 아이콘 자리에)·[다른 곳 고르기] [안내 시작] |
| 이동 중 (`/guide/:key`) | 왼쪽 남색 패널(어디로 가는 중인지, [안내 중지]), 오른쪽 층 지도(지금 위치, 지나온 길은 옅게·남은 길은 파랗게, 목적지 교실 강조). 지도는 아직 예시 평면도이고 로봇 위치는 이동 상태로 어림함. 실제로는 temi 지도와 위치를 그림 |
| 도착·설명 (`/arrival/:key`) | 왼쪽 남색 패널(도착한 장소), 오른쪽 줄 진행(2 / 4, 한 줄이 한 칸인 막대)과 지금 읽는 줄을 자막처럼 크게. 단어 중간에서 줄이 끊기지 않게 띄어쓰기 단위로 줄바꿈 |
| 관리 모드 PIN (`/admin`) | 왼쪽 남색 패널, 오른쪽 가운데에 작은 카드형 입력 칸 4개와 숫자 키패드 |
| 장소 관리 (`/admin/places`) | 장소 목록(아이콘, 이름, 층·분류·temi 키, 로봇 저장 상태), 줄마다 [미리 듣기] [이동 테스트], 줄을 누르면 장소 편집으로. 위쪽 [음성 설정] |
| 장소 편집 (`/admin/places/:key`) | 왼쪽 기본 정보(표시 이름, 로봇 장소 키, 분류, 층, 검색 키워드), 오른쪽 안내 멘트 3종(출발·도착·본 설명)과 멘트별 [미리 듣기]. 본 설명은 줄마다 번호가 붙은 입력 칸이고, 한 줄이 도착 화면의 한 페이지가 됨(줄 추가·지우기). 미리 들어 있는 설명을 고치고, [원래 설명으로]로 되돌림 |
| 음성 설정 (`/admin/tts`) | 왼쪽 목소리(여성·남성), 말하기 속도, 높낮이, 음량 슬라이더. 오른쪽 예문과 [이 설정으로 듣기]. [기본값으로] |
